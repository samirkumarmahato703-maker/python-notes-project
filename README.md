📌 About the Project

The Digital Notes Management System is a Python-based console application designed to manage text notes easily.

This application allows users to add, view, search, edit, and delete notes. All notes are stored permanently in a text file named "notes.txt".

🎯 Project Objectives

- Create and save new notes.
- View all saved notes.
- Search notes using keywords.
- Edit existing notes.
- Delete notes when they are no longer required.
- Store notes permanently using file handling.

⚙️ Features

1. Add Note: Create a new note with a title and content.
2. View All Notes: Display all saved notes.
3. Search Note: Search notes by title or content.
4. Edit Note: Update the content of an existing note.
5. Delete Note: Delete a note using its ID.
6. File Storage: Save notes in "notes.txt".

🛠️ Technologies Used

- Python 3
- Visual Studio Code
- File Handling
- String Methods
- CRUD Operations
